\section{Expanded Symbolic Coefficients}
\label{sec:expanded_symbolic_coefficients}

This section lists the expanded symbolic coefficients used by the analytical
\newblock{geometric} quotients. These expressions are not intended as the practical
implementation route; the main estimator uses the equivalent windowed matrix
form. They are included here so that the closed-form geometric construction is
fully auditable from terminal waveforms and their local derivatives.

The coefficients for the three-wire delta parallel equivalent are:

	\centering

		s_{1234} &=({v''''_{bc}} {v'''_{ab}}-{v''''_{ab}} {v'''_{bc}}) ({v'_{bc}} {v_{ab}}-{v'_{ab}} {v_{bc}})
