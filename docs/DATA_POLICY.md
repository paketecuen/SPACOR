# Data Policy

This repository does not contain private measurement data.

## Tracked

- MATLAB source code.
- Public documentation.
- Synthetic fixture generators.
- Public smoke/regression scripts.
- Historical 2021 explanatory notes.

## Not Tracked

- `.mat` files.
- Raw measurement files.
- Private laboratory or field datasets.
- Generated `results/` folders.
- Generated `.csv`, `.png`, `.pdf`, and log artifacts.
- Local paths to private data roots.

## Synthetic Reproduction

All public examples and tests should be reproducible from source code alone.
Synthetic fixtures are generated by MATLAB functions under
`matlab/+spacor/+fixtures/`.

## Future Data Releases

If real datasets are released later, they should be added as a separate,
documented data package with:

- consent/provenance;
- anonymization status;
- file format specification;
- checksums;
- license;
- scripts showing how to reproduce the paper figures from those data.
